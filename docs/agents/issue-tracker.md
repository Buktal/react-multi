# Issue tracker

Repository: https://github.com/Buktal/ReAct-M

Use GitHub issues for reported bugs and proposed features. The initial implementation is specified in `docs/SPEC.md` and requires no pre-existing issue.

Read an issue with `gh issue view NUMBER --repo Buktal/ReAct-M`. Before posting an issue or changing tracker state, follow the user's authorization for the current task.

Initial implementation review baseline: the empty repository commit `b9d2cc0d55231b3d33cb1db5df279eda695fc87c`. Review the implementation against `docs/SPEC.md` and `CONTRIBUTING.md`.
